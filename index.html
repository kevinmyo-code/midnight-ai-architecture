Architecture

A driver's voice enters at the top; it either resolves against a pull-based tool (a direct database or OBD read, or a side-effecting action) or gets delegated to a bounded sub-agent investigation loop. Nothing is pre-injected — every fact the model uses is fetched on demand.

Layers, mapped to what shipped

Orchestration

Gemini Live speech-to-speech

A WebSocket session to Gemini Live drives the whole loop: half-duplex, server-side voice-activity detection, roughly two-second round-trip. The system instruction is split — a persona-and-rules block cached for two minutes, and a fresh live-context block (location, now-playing, vehicle, driver) rebuilt every conversation — so most turns pay only the fresh-context token cost.

GeminiLiveSession.kt buildBaseInstruction() buildLiveContext()
Tool layer

Pull-based context, not pre-injection

40+ function-calling tools split into zero-token data reads (database and OBD lookups), zero-token actions (side effects — music, navigation, logging), and sub-agent delegation. New domains default to a tool; nothing gets pre-loaded into the prompt on the chance it might be needed.

LiveToolbox.kt get_trend recall_memory control_music start_navigation
Sub-agents

Bounded investigation loops

Diagnostic, maintenance, and symptom-triage work delegates to specialist Gemini Flash workers that pull from a read-only toolbelt in a capped loop — four model calls maximum, 30-second budget, one-shot fallback if the budget runs out. Simpler agents (cold-start reasoning, music taste) skip the loop entirely and run a single typed call, since they need no adaptive tool-pulling.

Vehicle I/O

Live diagnostics over Bluetooth

An ELM327 adapter is read over Bluetooth RFCOMM: raw ELM AT and OBD responses are hand-parsed into PIDs, diagnostic trouble codes, emissions readiness monitors, and Mode-02 freeze frames. A 30-second telemetry loop writes to a time-series table with a rolling retention purge, gated so voice always wins the shared serial port.

ObdBluetoothManager.kt ObdResponseParser.kt TelemetryRecorder.kt
Integrations

Music, navigation, recalls

Spotify via the App Remote SDK plus the Web API under PKCE OAuth (no client secret shipped); embedded turn-by-turn navigation on the Mapbox Navigation SDK with a bring-your-own public token; VIN decode and open recalls against NHTSA's vPIC API. Every third-party key in the app is the driver's own — nothing routes through a developer-hosted backend.

Spotify App Remote Mapbox Nav SDK v3 NHTSA vPIC
App shell

Compose UI and persistent service

The whole app is a launcher: Jetpack Compose UI, a foreground service holding the microphone and running background telemetry, health, and drive-detection loops, a system-overlay companion badge for tap-to-talk while another app has focus, and a Room database carried through 12 additive schema migrations with device-verified upgrade tests — no destructive fallback, ever.
